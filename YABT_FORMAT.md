# YABT フォーマット

`.yabt` はアニメーション合成ツリーを格納するファイルフォーマットです。

---

## 全体構造

`.ybr` と同じく [CBOR (RFC 8949)](https://www.rfc-editor.org/rfc/rfc8949) で書かれています。
ファイル全体がちょうど 1 個の CBOR 値で、中身は 3 要素の配列です。

```
[ "YABT", version, ノード ]
```

| 位置 | 型   | 内容                                 |
| ---- | ---- | ------------------------------------ |
| 0    | text | マジック。必ず `"YABT"` (4 文字)     |
| 1    | uint | フォーマットのバージョン。現在は `1` |
| 2    | map  | ツリーの根になるノード 1 個          |

- 1 ファイルにつきツリーは 1 本です。複数のツリーを使うときはファイルを分けます。

---

## 値の書き方

| 種類        | CBOR での型      | 備考                                                       |
| ----------- | ---------------- | ---------------------------------------------------------- |
| 整数 / 列挙 | uint または nint | 列挙は C の enum の値をそのまま書く                        |
| 実数        | float (64bit)    | 書き出しは常に倍精度。読み込みは半 / 単 / 倍精度いずれも可 |
| 文字列      | text             | UTF-8。NUL 終端ではない                                    |
| 省略        | null             | 「無い」ことを表す。キー自体を省いても同じ扱い             |

読み込み側は **未知のキーを無視** します。将来キーが増えても古い実装で読めます。
入っていないデータに関しては既定の値を採用します。

---

## ノード

ツリーのノードはすべて CBOR の map です。どの種別でも次の2つを持ちます。

| キー        | 型   | 既定   | 内容                                                         |
| ----------- | ---- | ------ | ------------------------------------------------------------ |
| `type`      | uint | (必須) | ノードの種別。下の表を参照                                   |
| `unique_id` | text | `""`   | `YbrAnimBlendTreeFind()` で引くための名前。使わないなら `""` |

`type` の値は `YbrAnimBlendNodeType` と同じです。

| 値  | 名前                 | 意味                     |
| --- | -------------------- | ------------------------ |
| 0   | `YBR_ABN_SOURCE`     | アニメーションそのもの   |
| 1   | `YBR_ABN_LERP`       | 2 つの入力を線形補間する |
| 2   | `YBR_ABN_ADD`        | 2 つの入力を加算する     |
| 3   | `YBR_ABN_TRANSITION` | 複数の入力を切り替える   |

### SOURCE (`type` = 0)

再生するアニメーションを1つ指定します。

| キー         | 型    | 既定   | 内容                             |
| ------------ | ----- | ------ | -------------------------------- |
| `name`       | text  | (必須) | アニメーション名                 |
| `loop_mode`  | uint  | `0`    | `0` = 1回だけ再生 / `1` = ループ |
| `play_speed` | float | `1.0`  | 再生速度の倍率。 0.0以上         |

### LERP (`type` = 1) / ADD (`type` = 2)

| キー             | 型                 | 既定   | 内容                                                       |
| ---------------- | ------------------ | ------ | ---------------------------------------------------------- |
| `weight`         | float              | `0.0`  | 混ぜ具合。`0.0` で `input` のみ、`1.0` で `mix_input` のみ |
| `filtered_bones` | array(text) / null | null   | 合成から外すボーン名。無ければ null                        |
| `input`          | map                | (必須) | 1つ目の入力                                                |
| `mix_input`      | map                | (必須) | 2つ目の入力                                                |

### TRANSITION (`type` = 3)

| キー                 | 型         | 既定   | 内容                     |
| -------------------- | ---------- | ------ | ------------------------ |
| `index`              | int        | `0`    | 最初に再生する入力の番号 |
| `transition_seconds` | float      | `0.0`  | 切り替えにかける秒数     |
| `inputs`             | array(map) | (必須) | 入力のノード。1 個以上   |

---

## 制限

| 項目                   | 値                       |
| ---------------------- | ------------------------ |
| ノードの入れ子の深さ   | `YABT_MAX_DEPTH` (64)    |
| CBOR の入れ子の深さ    | `CBOR_MAX_DEPTH` (64)    |
| 評価に要るスタック段数 | `YBR_ABT_MAX_STACK` (32) |

---

## 例

`"Walk"` をループ再生するだけの、いちばん小さなツリーです。

```c
YbrAnimBlendNode n = {0};
n.uniqueId = "walk";
n.type = YBR_ABN_SOURCE;
n.source.name = "Walk";
n.source.loopMode = YBR_ALM_LOOP;
n.source.playSpeed = 1.0f;
```

CBOR の診断表記では次のようになります。

```
[
  "YABT",
  1,
  {
    "type": 0,
    "unique_id": "walk",
    "name": "Walk",
    "loop_mode": 1,
    "play_speed": 1.0
  }
]
```

実際のバイト列は 70 バイトです。

```
83                                      # array(3)
   64 59 41 42 54                       # "YABT"
   01                                   # 1
   A5                                   # map(5)
      64 74 79 70 65                    # "type"
      00                                #   0 (SOURCE)
      69 75 6E 69 71 75 65 5F 69 64     # "unique_id"
      64 77 61 6C 6B                    #   "walk"
      64 6E 61 6D 65                    # "name"
      64 57 61 6C 6B                    #   "Walk"
      69 6C 6F 6F 70 5F 6D 6F 64 65     # "loop_mode"
      01                                #   1 (LOOP)
      6A 70 6C 61 79 5F 73 70 65 65 64  # "play_speed"
      FB 3F F0 00 00 00 00 00 00        #   1.0
```

もう少し実用的な例として、走りと歩きを混ぜたものと待機を切り替えるツリーはこうなります。

```
[
  "YABT", 1,
  {
    "type": 3, "unique_id": "locomotion",
    "index": 0,
    "transition_seconds": 0.25,
    "inputs": [
      {
        "type": 1, "unique_id": "mix",
        "weight": 0.3,
        "filtered_bones": ["head"],
        "input":     { "type": 0, "unique_id": "walk", "name": "Walk",
                       "loop_mode": 1, "play_speed": 1.0 },
        "mix_input": { "type": 0, "unique_id": "run", "name": "Run",
                       "loop_mode": 1, "play_speed": 1.0 }
      },
      { "type": 0, "unique_id": "idle", "name": "Idle",
        "loop_mode": 1, "play_speed": 1.0 }
    ]
  }
]
```
